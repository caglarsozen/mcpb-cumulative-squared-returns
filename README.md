# MCPB: cumulative squared-return forecasts

Replication materials for **Positive Calibration of Cumulative Squared-Return Forecasts: Shape Coherence and the Role of Label Maturity**.

The maturity-calibrated positive blend (MCPB) combines an isotonic HAR-style ridge path and a cumulative exponentially weighted moving-average path. Two nonnegative coefficients adjust the forecast level and composition using only outcomes available at the forecast close. The coefficient sum need not equal one.

## Reproduce the study

Download this repository using **Code → Download ZIP**, extract it, and open a terminal in its root folder. The estimation step uses base R; publication outputs and independent numerical checks use Python.

```sh
Rscript run.R check outputs/check
Rscript run.R full outputs/full
python -m pip install -r requirements.txt
python code/verify_full_run.py outputs/full
Rscript code/verify_arrays.R outputs/full outputs/array-audit
python build_outputs.py --results-dir outputs/full
```

The full command refits ridge models and selects their penalties, estimates the combination coefficients, and computes 4,999 moving-block bootstrap draws per block-length setting. It writes 120 case folders with fitted arrays, origin losses, choices, accuracy, and inference. Model fitting is **not repeated inside each bootstrap draw**. The full experiment uses the fixed original prices and requires no live data download.

The exporter writes **13 complete LaTeX tables** (T1–T5 and A1–A8), **five vector PDF figures**, and 300-dpi PNG copies under `outputs/full/publication/`. Main figures are Fig1–Fig4; the supplementary figure is FigA1. Tables A3–A6 include the separately archived benchmark and TV experiments described below; running MCPB does not refit those historical estimators.

For a quick reproduction of publication outputs from the supplied summaries, without fitting models:

```sh
python build_outputs.py
python tests/check_publication.py
python code/verify_recorded_solutions.py
```

These outputs appear under `outputs/frozen/`. Output checks are specific to the frozen 2019–2024 study; the exporter is not an unrestricted interface for new data or changed specifications.

**Tested environment:** R 4.3.3 and Python 3.12.14, with the exact Python package versions in `requirements.txt`. See [reproduction instructions](docs/REPRODUCTION.md), [method mapping](docs/METHOD.md), and [validation scope](docs/VALIDATION.md). Save and run the R files as files; do not paste only their final function call into the R console. This preserves source provenance.

## Evidence and interpretation

The study retains BTC, ETH, SPY, GLD, TLT, QQQ, IWM, EFA, EEM, XLF, XLE, XLU, SLV, LQD, and VNQ. The sample ends on **31 December 2024**. Four maximum horizons (10, 20, 30, 40 observed returns) and expanding/rolling estimation give 120 related cases. Cryptocurrency and ETF horizons have different calendar spans.

At H=30, MCPB has lower path MSE than the monthly Ridge–EWMA combination for 11 of 15 assets in each window; asset-level median reductions are 15.60% and 9.15%. No favorable comparison against that combination survives the specified primary Holm correction. The full-path positive control supplies no established incremental maturity benefit; near-term and QLIKE comparisons are weaker. GLD and SLV remain in all reported comparisons. The principal ridge paths already satisfy the shape restriction.

These are **exploratory results on data used during method development**, not a preregistered or untouched holdout evaluation. Reproducibility does not establish general superiority.

The earlier additional benchmarks and TV procedure are preserved as **aggregate contextual evidence**. Their full fitted configurations, underlying additional-benchmark paths, and historical per-origin TV segment histories are unavailable here. No fresh fitting or paired inference is claimed for them.

The large, fresh fitted arrays are generated by the full command and supplied separately with the manuscript as Online Resource 3. They are not committed to this repository. Online Resource 1 contains the proofs and supplementary analysis; Online Resource 2 is the anonymous code/data package for journal review.
